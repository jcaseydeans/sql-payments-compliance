# SQL for Payments & Compliance Reporting

Self-study SQL portfolio built while refreshing my SQL skills for payments
operations and compliance work.

## Data
`payments_practice.db` is a **fictional** SQLite database (25 made-up merchants,
Jan–Sep 2026): ACH entries and returns, card transactions, chargebacks, and
daily settlements. No real company or customer data is used.
